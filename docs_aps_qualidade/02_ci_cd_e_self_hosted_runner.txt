2.2 Justificativa (PR #93)
--------------------------

- PR #93, título no GitHub: "feat(ci): usar self-hosted runner na OSTG 0.2". Branch
  ci-self-hosted. Mergeado em 2026-09-21T20:53:21Z, merge commit 76483d9a.
  Os fatos citam o título "ci: self-hosted runner OSTG 0.2". O título do GitHub é o que
  está no repositório.
- Corpo do PR (cmd: gh pr view 93 --json title,body), citado integralmente:
    "Usar runner self-hosted da OSTG 0.2 para evitar dependência de minutos do GitHub Actions"
- Commits (corpo vazio nos três):
    c101488  feat(ci): usar self-hosted runner na OSTG 0.2
    05687d1  ci: complete migration of all quality-gate jobs to self-hosted runner
    97b1ece  ci: bump node-version to 22 to fix undici markAsUncloneable regression in node 20.20
- Razão declarada: evitar dependência de minutos do GitHub Actions.
- Razões não declaradas no repositório: hardware dedicado, custo, cache persistente e
  arquitetura ARM. Para cada uma: "não declarado no repositório".
- Razão declarada para o cache (não para o runner): quality-gate.yml:32-33 e 64-65 (ver 1.2).
- Razões inferidas (não declaradas):
  - Minutos do GitHub Actions: o quality gate roda 6 jobs por push e por PR, então o consumo
    de minutos seria o motivo principal [inferido].
  - Hardware dedicado: VM ARM com 2 vCPU e 11 GiB de RAM (2.3).
  - VM ARM no OCI Always Free: shape VM.Standard.A1.Flex, com a tenancy no limite de 200 GB
    de block storage [fatos].
  - Cache persistente: _work/_tool guarda node, uv, Python e sonar-scanner entre
    execuções (2.3).
- Consequências observadas:
  - Os testes rodam em aarch64, não em x86_64. Pacotes com binário nativo (torch, sherpa-onnx,
    onnxruntime) precisam de wheels ARM [inferido]. O PR #103 (2026-10-01) passou a instalar
    torch de CPU no CI e no release [fatos].
  - Dos últimos 12 runs do quality-gate em main (cmd: gh run list --branch main --workflow
    quality-gate.yml --limit 12), 10 terminaram com failure, 1 cancelled e 1 ainda
    em andamento no momento da coleta [gh].
  - Causas verificadas: os runs 37855744558 (2026-10-08) e 37867326230 (2026-10-09)
    falharam no job SonarCloud com "CE Task finished abnormally with status: FAILED"
    (log do run, passo SonarCloud) [gh]. As causas dos demais não foram investigadas.
