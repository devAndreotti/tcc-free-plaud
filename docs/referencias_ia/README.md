# Referencias IA

## Objetivo desta pasta

Esta pasta guarda material de apoio para implementacao, pesquisa tecnica e guias produzidos com ajuda de IA.

## Regra de uso

Os arquivos daqui nao substituem a documentacao oficial do projeto.

Em caso de conflito, seguir esta ordem:

1. `docs/arquitetura/`
2. `docs/tcc/`
3. `docs/planejamento/`
4. `docs/plano_execucao/`
5. `docs/referencias_ia/`

## Uso recomendado

Usar esta pasta para:

- pesquisas tecnicas
- comparativos de bibliotecas
- rascunhos de abordagem
- guias de implementacao

Nao usar esta pasta como unica fonte de decisao arquitetural.
