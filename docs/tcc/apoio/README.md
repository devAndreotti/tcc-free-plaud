# Apoio Academico

## Objetivo

Esta pasta guarda material auxiliar para a escrita do TCC.

Ela pode conter:

- notas de pesquisa
- analises intermediarias
- rascunhos de argumentacao
- versoes auxiliares da revisao bibliografica

## Observacao importante

Parte deste material foi produzida em fases anteriores do projeto e pode mencionar:

- paths antigos
- nomes antigos de arquivos
- referencias de contexto que hoje estao desatualizadas

Esses arquivos foram preservados como historico academico e apoio, nao como contrato canonico de navegacao do repositorio.
