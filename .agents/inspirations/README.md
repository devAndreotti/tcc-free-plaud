# Inspirations

Esta pasta guarda referências visuais para o projeto.

O objetivo não é copiar telas prontas, e sim extrair:

- paleta de cor
- tipografia
- densidade visual
- linguagem de superfícies
- ritmo de layout
- tratamento de estados e componentes

## O que colocar aqui

- screenshots de apps
- recortes de dashboards
- páginas web
- PDFs de referência visual
- capturas de interfaces acadêmicas, productivas ou editoriais

## Como nomear

Use nomes descritivos:

- `dashboard-notion-dark.png`
- `editorial-knowledge-app-01.png`
- `clean-research-tool.pdf`

## Boa prática

Para cada referência importante, vale incluir um comentário rápido em um arquivo `.md` ao lado com:

- o que gostou
- o que não quer copiar literalmente
- que parte interessa: cor, tipografia, layout, densidade, componentes

## Regra

Não encha a pasta com dezenas de arquivos aleatórios.
Prefira poucas referências fortes e bem escolhidas.

## Uso

Esta pasta é consumida pela skill local:

- `.agents/skills/inspiration-to-theme/SKILL.md`

e pelo workflow:

- `.agents/workflows/design-from-inspirations.md`
