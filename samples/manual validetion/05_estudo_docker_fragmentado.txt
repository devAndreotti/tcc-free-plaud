um trecho que eu copiei do livro e vale reler:

O modelo de camadas das imagens Docker é uma das características mais elegantes do sistema. Cada instrução no Dockerfile que modifica o sistema de arquivos — como RUN, COPY ou ADD — cria uma nova camada somente leitura sobre as camadas anteriores. Quando um container é iniciado, o Docker adiciona uma camada de escrita temporária no topo dessas camadas somente leitura, utilizando um mecanismo chamado copy-on-write. Isso significa que dois containers baseados na mesma imagem compartilham todas as camadas de leitura, e cada um possui apenas sua própria camada de escrita isolada. O resultado prático é uma economia significativa de espaço em disco e uma velocidade de inicialização muito maior do que a de máquinas virtuais tradicionais, que precisam copiar todo o sistema de arquivos a cada instância.
