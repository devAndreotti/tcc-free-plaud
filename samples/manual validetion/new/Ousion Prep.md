### Técnicas

**"Me explica o que é uma API REST."** → "É uma forma de comunicação entre sistemas usando o protocolo HTTP, onde cada endpoint representa um recurso. Usamos os verbos HTTP — GET pra buscar, POST pra criar, PUT/PATCH pra atualizar, DELETE pra remover. A resposta geralmente vem em JSON. Já consumi e criei APIs REST — no projeto do polichinelo, por exemplo, o Flask servia os dados do MediaPipe e eu consumia no front com fetch."

---

**"O que é Git e como você usa no dia a dia?"** → "Git é o sistema de controle de versão que uso em todos os projetos. No trabalho em grupo da faculdade foi essencial — cada um trabalhava na sua branch, fazíamos pull request, revisávamos antes de mergear na main. Evitou muita dor de cabeça. Tenho o GitHub ativo com mais de 50 projetos, e procuro sempre documentar bem o README."

---

**"O que você entende por estrutura de dados?"** → "São formas de organizar dados de forma eficiente dependendo da operação que você precisa fazer. Lista, pilha, fila, árvore, hash table — cada uma tem complexidade diferente pra busca, inserção e remoção. Na faculdade de Ciência da Computação isso é cobrado na teoria e na prática. É algo que influencia muito quando você precisa otimizar código que processa volumes grandes de dados."

---

**"Você tem experiência com testes automatizados?"** → "Sim. Usei Playwright no projeto do polichinelo pra automatizar testes da interface — simulava cliques, preenchimento de formulário, verificava se os dados do back apareciam corretamente no front. Foi a primeira vez que apliquei testes automatizados de forma estruturada, e foi interessante ver o quanto isso economiza tempo de teste manual repetitivo."
